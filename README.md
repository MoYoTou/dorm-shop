# dorm-store 宿舍小卖铺小程序

原生小程序 + 微信云开发（CloudBase），单小程序双角色（顾客 / 商家）。
核心功能：商品与库存展示、购物车、即时单 + 预定单、自定义营业时间、
订单明细、联系商家、退款双通道（商家直退 / 顾客申请需商家审批）、
微信支付（可切换货到付款模式先跑通）。

## 目录结构

```
miniprogram/            小程序前端
  pages/                用户端 8 个页面
  pages-admin/          商家端 4 个页面（分包，入口仅管理员可见）
  utils/                云函数调用封装 / 登录角色 / 营业时间判断
cloudfunctions/         云函数（7 个，按 action 路由）
  login                 获取 openid、识别管理员、建档
  init                  初始化 settings 默认配置 + 示例商品 + 设置管理员
  settings              读取 / 更新营业设置（更新仅管理员）
  goods                 商品列表 / 新增编辑 / 上下架 / 库存调整
  order                 下单（事务扣库存）/ 列表 / 详情 / 取消 / 推状态
  refund                顾客申请退款 / 商家审批 / 商家一键直退
  pay                   微信支付下单 + 支付回调
```

## 部署步骤

1. 先在 mp.weixin.qq.com 注册小程序，拿到真实 AppID
   （注意：测试号 touristappid 无法开通云开发，必须真实 AppID），
   微信开发者工具 → 导入本目录 → 填入你的 AppID。
2. 开通云开发：开发者工具点「云开发」→ 创建环境（记下环境 ID）。
3. 把环境 ID 填到 `miniprogram/app.js` 的 `wx.cloud.init({ env: '你的环境ID' })`。
4. 右键每个云函数目录 → 「上传并部署：云端安装依赖」（共 7 个）。
5. 部署完后，在小程序「我的」页点「初始化数据」——
   **init 云函数会自动创建** `goods` `orders` `refunds` `settings` `users` 5 张表，
   无需手动建表。若想手动建，权限建议：settings / goods 选「所有用户可读，仅创建者可写」，
   其余选「仅创建者可读写」（写操作都走云函数，安全）。
   （或控制台手动运行 init 云函数）：
   - 写入默认营业时间 / 配送费 / 联系方式
   - 创建 4 个示例商品
   - **把你的 openid 设为管理员**，首页右下角即出现「管理」入口。

## 上线前必做的 3 件事（否则朋友打开会看到假数据）

1. **改联系方式**：商家端 → 营业设置 → 手机号 / 微信号 / 店铺公告。
   默认是占位值 `13800000000` / `xiaomapu`，不改的话同学根本联系不上你。
   联系方式显示在首页「我的」和订单详情页。
2. **核对商品与库存**：商家端 → 商品与库存，上传图片、填真实价格库存。
   没图的商品顾客端只显示灰色占位块。
3. **确认营业时间**：默认 18:00–23:30，非营业时段只能下预订单。

> 当前是货到付款（cod），建议在公告里写清「送到宿舍门口当面付 / 微信转账」，
> 避免同学以为已经付过钱。

## 怎么让别人用上（分发）

### 路径 A：体验版 —— 今天就能用，最多 15 人（个人主体上限）

不用审核、不用资质，适合先在宿舍楼小范围跑起来。

1. **开发者工具**右上角点「**上传**」→ 版本号填 `1.0.0`，备注随便写 → 确定。
2. 打开 **mp.weixin.qq.com** → 用小程序账号登录 → 左侧「**管理**」→「**版本管理**」。
3. 在「开发版本」里找到刚上传的这版 → 点「**选为体验版**」。
4. 左侧「**成员管理**」→「**体验成员**」→ 添加。
   ⚠️ 填的是对方的**微信号**（不是昵称、不是手机号）。微信号在对方微信
   「我 → 头像 → 微信号」那一行能看到。
5. 回到「版本管理」→ 体验版右边「**二维码**」→ 下载图片，发到微信群。
   扫码即可使用，**对方不需要接受邀请**。

注意：
- 体验成员上限 **15 人**（个人主体）；个体工商户主体是 30 人。
- 每次在开发者工具重新「上传」后，需要重新「选为体验版」，体验版才会更新。
- 体验版搜不到、分享不了小程序卡片，只能靠扫码或二维码进。

### 路径 B：正式发布 —— 不限人数，能被搜到

需要先满足资质，再提交审核：

1. 注册**个体工商户**（约 3-5 个工作日）→ 把小程序主体变更过去。
2. 公众平台 →「**设置**」→「**基本设置**」→「**服务类目**」，添加类目。
   卖零食属食品类目，可能要《食品经营许可证》。
3. 「版本管理」→ 开发版本 →「**提交审核**」，按提示填测试账号等信息。
4. 审核通过（通常 1-7 天）→ 点「**发布**」，之后：
   - 微信搜小程序全名能搜到
   - 可以转发小程序卡片到群 / 好友
   - 可以生成**小程序码**（公众平台 →「设置」→「小程序码」），打印贴在宿舍楼

> 现实建议：**先用路径 A 跑起来**。15 个人对一栋宿舍楼起步够用了，
> 等订单跑顺、确认这事能赚钱，再去办个体工商户走路径 B。

## 微信支付开通（路线：个体工商户）

当前代码已完整实现支付链路，但默认 `payMode = 'cod'`（货到付款），
无商户号也能跑通全流程。接入在线支付的步骤：

1. 注册个体工商户（各地政务网可办，约 3-5 个工作日）。
2. 用个体工商户主体注册小程序（个人主体无法开通支付和电商类目）。
   卖零食属食品类目，类目审核可能要求《食品经营许可证》，提前准备。
3. 申请微信支付商户号（pay.weixin.qq.com），并与小程序 AppID 绑定。
4. 云开发控制台 → 设置 → 微信支付，按指引开通并配置商户号。
5. 商家端「设置」页把收款模式切换为「在线支付」，填入商户号（subMchId）。
6. 退款：在线支付的退款走 `pay` 云函数 refund action
   （骨架已预留接口，需上传商户 API 证书到云函数环境）。

## 关键业务规则（开发约定）

- 下单即扣库存（数据库事务防超卖），取消 / 退款成功自动回补。
- 非营业时间：即时单关闭，可下预订单（配送时间必须落在营业时段内）。
- 顾客退款：仅「待接单 / 备货中」可申请 → 商家审批，
  同意则退款并回补库存，拒绝需填理由、订单继续。
- 商家退款：任意未完成订单可一键直退，无需顾客确认，立即执行。
- 管理员判定：`settings` 表 `adminOpenids` 数组包含用户 openid。
